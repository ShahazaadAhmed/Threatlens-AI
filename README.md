# Threatlens AI

An AI assisted cyber threat intelligence platform focused on
threat relationship visualization, indicator exploration,
investigations, and intelligence reporting.

## Current Status

Initial project structure established.

The first phase will focus on a Streamlit frontend prototype
using simulated data. Backend and model integration will be
considered after the interface is validated.

## Planned Modules

- Overview Dashboard
- Threat Graph
- Indicator Explorer
- Investigations
- Reports
